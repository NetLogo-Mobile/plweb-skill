# 操作权限与结果

| 账号身份 | 操作 |
|---|---|
| 作品作者 | 发布与编辑自己的作品、删除自己的作品、隐藏和恢复自己的作品、邀请及移除合作者 |
| 志愿者 | 警告用户、移动作品、隐藏他人作品、添加或撤销知识库；不能加精选或封禁用户 |
| 编辑 | 添加或撤销精选和知识库、社区管理与封禁；封禁天数1到30 |
| 管理员 | 任命编辑、编辑他人作品正文；封禁天数1到365 |

封禁Length=0表示100年。封禁会清除身份，解封不恢复原身份。正常批量操作使用同一账号，权限错误直接返回服务器原始Status、Message和Data，不更换账号重试。

## 隐藏、删除与恢复

- `RemoveExperiment`传`Hiding=true`为隐藏。作者隐藏自己的作品后Visibility=1；有管理权限的账号隐藏他人作品后Visibility=2。
- 传`Hiding=false`为从服务器直接删除自己的作品，删除后不能恢复。GetSummary不再返回可读摘要。
- `RestoreExperiment`只恢复隐藏作品，恢复后Visibility=0，不能恢复已删除作品。恢复不返还扣除的金币。
- 隐藏会扣除作品作者100金币，包括由他人执行的管理隐藏。删除也会扣金币；每项结果应说明实际变化。

本地CLI用`remove --mode delete/hide/restore`。云端用`remove_work(mode="delete"|"hide")`及`restore_work`。隐藏他人作品时保持其作者、正文和模型不变。

## 错误

同时检查HTTP状态与业务Status。保留服务器Message和字段错误Data，隐藏账号凭据。HTTP200但Status非200仍是失败。写超时先读取目标状态，不自动重复发布、扣币或发通知。
